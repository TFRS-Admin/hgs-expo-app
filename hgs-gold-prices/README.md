# HGS Gold Prices

Expo (React Native, TypeScript) app for Houston Gold & Silver. It runs on iPhone through Expo Go or an EAS build, and as a static web build.

## Run

```bash
npm install
npx expo start        # scan the QR code with Expo Go, or press w for web
```

## Checks

```bash
npx expo lint
npx tsc --noEmit
```
